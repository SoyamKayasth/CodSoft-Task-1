# CodSoft-Task-2

## 🌐 Landing Page Project

This project is a simple and beginner-friendly landing page built using **HTML** and **CSS**. It includes a header, hero section, about section, service section, contact block, and footer. The goal is to practice the basics of layout, alignment, spacing, and color usage while building a visually clear and user-friendly page.

---

## 📁 Project Structure

```
Landing-Page/
│
├── index.html
├── style.css
└── README.md
```

---

## ⭐ Features

* Clean layout with clear sections
* Responsive hero area with heading, text, and button
* About section describing the purpose
* Services displayed in simple cards
* Contact section with call-to-action
* Footer with copyright text

---

## 🧰 Technologies Used

* **HTML5**
* **CSS3 (Flexbox, basic layout styling)**

---
## 🚀 How to Run This Project

1. Download or clone the repository:

   ```
   git clone https://github.com/your-username/Landing-Page.git
   ```
2. Open the folder.
3. Double-click **index.html** to view it in your browser.
